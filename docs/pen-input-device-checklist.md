# 펜 입력 실기기 검증 체크리스트

`docs/frontend-plan.md` Phase 1 완료 기준을 실제 태블릿(애플펜슬 / S펜)에서 확인하기 위한 체크리스트다. 코드로는 검증할 수 없어 사용자가 직접 실기기에서 테스트한 뒤 이 문서에 결과를 채워 넣는다. 대상 컴포넌트: `src/lib/pen/PenCanvas.tsx`.

## 사용법

각 항목을 실기기에서 테스트한 뒤 `- [ ]`를 `- [x]`로 바꾸고, 비고 칸에 기기 기종·OS·브라우저와 관찰한 내용을 적는다.

- 관련 코드: `handlePointerDown`(`PenCanvas.tsx:45-52`) / `handlePointerMove`(`PenCanvas.tsx:54-59`)가 `e.pressure`를 스트로크 각 점에 기록하고, `getStroke(stroke, { size: 6 })`가 이를 굵기에 반영한다.

### 2. 팜 리젝션 (손바닥 오터치 무시)

- 관련 코드: `handlePointerDown`(`PenCanvas.tsx:47`)에서 `e.pointerType === 'touch' && e.width > 20`인 이벤트를 무시. 주석에 "실기기 확인 후 조정 대상"으로 명시된 임계값이다.
- 확인 방법: 손바닥을 캔버스 위에 얹은 채로 펜으로 글씨를 써서, 손바닥 접촉이 획으로 그려지지 않는지 확인. 만약 손바닥이 획으로 그려지거나 반대로 펜의 넓은 접촉이 무시된다면, `e.width` 값을 로그로 찍어 임계값 `20`을 기기에 맞게 조정 필요.
